# Data Analytics Projects

A portfolio collection focused on **HR Analytics** and **Retail Sales & Profitability** using Python and Power BI.

## Business Analytics Themes

### 1. HR Analytics — Employee Attrition
- Analyze employee data
- Explore drivers associated with resignations
- Use Python and Power BI to turn workforce data into decision-ready insights

### 2. Retail Business Profitability — Superstore
- Analyze sales and profit
- Identify business performance patterns
- Use Python and Power BI to support commercial decision-making

## Dataset

The original project documentation states that public datasets from Kaggle were used.

## Tools

- Python
- Power BI
- GitHub

## Workflow

1. Prepare the dataset
2. Perform exploratory analysis
3. Identify relevant business dimensions and KPIs
4. Build visual analysis
5. Interpret findings
6. Translate findings into business recommendations

## Portfolio Value

This repository demonstrates breadth across two common business analytics domains: workforce analytics and retail profitability.
